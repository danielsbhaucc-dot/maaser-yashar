# מעשר ישר

אפליקציית React Native (Expo) לחישוב **מעשר כספים** ו**חומש (20%)** עם פירוט הלכתי, ומחשבון + מדריך להחזר מס לפי **סעיף 46**.

## הרצה

```bash
npm install
npx expo start
```

לאחר מכן סרקו QR ב-Expo Go, או לחצו `w` לדפדפן.

## מסכים

1. **מעשר** — הכנסות, ניכויי מס, שיטות הלכתיות, מעשר/חומש, יתרה לתת
2. **החזר מס** — אומדן זיכוי 35% (יחיד) / 30% (חברה), תקרות ומינימום
3. **הנחיות** — איך ומתי להגיש, קישורים לרשות המסים

## הערות

- אינה פסק הלכה ואינה ייעוץ מס.
- נתוני סעיף 46 לפי פרסומים ציבוריים (מינימום 207 ₪, תקרה כ־10.35M לשנים 2024–2027).
